# IoT-Based Smart EMS System

## Project Overview
This project focuses on an IoT-based Electrical Muscle Stimulation (EMS) system concept with real-time patient monitoring.

 1. Objectives
- Develop an ESP32-based monitoring system.
- Collect sensor data for monitoring.
- Display sensor readings on an LCD.
- Explore IoT-based remote monitoring.
- Include safety monitoring and alerts.

2. Hardware Components
- ESP32 development board
- EMG sensor
- MAX30100 sensor
- DS18B20 temperature sensor
- LCD display
- Buzzer and LEDs

3. Software and Tools
- Arduino IDE
- ESP32
- IoT platform
- Circuit simulation software

4. Project Status
Prototype development and testing.
